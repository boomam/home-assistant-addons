# Updates
Pangolin-CLI version should automatically update through a GitHub Action.
Base Image will be a manual process for the time being.

# Versioning
First three digits are Pangolin-CLI's version number.  
The letter & number are bug fix releases where said issue is not with Pangolin-CLI, but with this template.
